# law-links

FastAPI-сервис, выделяющий из русского текста юридические ссылки вида `пп. 1 п. 1 ст. 374 НК РФ` и возвращающий их структурой `law_id / article / point_article / subpoint_article`. Условие задания: [docs/TASK.md](docs/TASK.md).

## Быстрый старт

```bash
docker build -t law-links-service .
docker run -d -p 8978:8978 --name law-links-container law-links-service

curl -X POST "http://localhost:8978/detect" \
     -H "Content-Type: application/json" \
     -d '{"text": "Согласно статье 23 Налогового кодекса и ст. 145 Гражданского кодекса"}'
# {"links":[{"law_id":15,"article":"23",...},{"law_id":5,"article":"145",...}]}

docker stop law-links-container && docker rm law-links-container
docker rmi law-links-service
```

Swagger: http://localhost:8978/docs, проверка состояния: `GET /health`.

Локально без Docker (Python 3.11+):

```bash
pip install -r requirements-dev.txt
python main.py            # или: make run
make test                 # pytest
make eval                 # precision / recall / F1 на tests/gold.json
make audit                # отчёт о качестве law_aliases.json -> docs/aliases_audit.md
```

## Как работает

1. `normalize` приводит кавычки, `ё`, неразрывные пробелы и тире к одному виду, длина текста не меняется, поэтому позиции совпадают с исходником.
2. `AliasIndex` на старте (~1.5 с) лемматизирует pymorphy3 все 18.7k алиасов и складывает их в trie по леммам. В тексте ищется самое длинное совпадение, так находятся склонённые формы: «Гражданского процессуального кодекса Российской Федерации» -> id 6.
3. `grammar` регулярным выражением находит цепочки `[подпункт] [пункт | часть] [статья]` со списками значений: `12`, `4.6`, `43.2-6`, `а`, `1, 2 и 3`, `а, б и с`.
4. `RuleBasedExtractor` связывает цепочку с ближайшим законом справа. Между ними допускаются только служебные слова вроде «Федерального закона», точка запрещена.
5. Перечисления раскрываются декартовым произведением: `пп. 1, 2, 3 п. 2 ст. 3 НК РФ` -> 3 объекта.

Короткие аббревиатуры (`НК`, `УК`) в нижнем регистре принимаются, только если слово не является обычным словом словаря (`как`, `ск`).

## Принятые решения

| Случай | Поведение |
|---|---|
| `п. 10 АПК` (нет статьи) | `article: null, point_article: "10"` |
| закона нет в словаре (`рандомного кодекса`, `ФЗ №20-456`, Конституция) | ссылка не возвращается |
| алиас принадлежит нескольким законам (580 случаев) | берётся наименьший id |
| `часть` | пишется в `point_article` |
| повторы одной ссылки | сохраняются, порядок как в тексте |

## Качество

`tests/gold.json`: текст из условия задания (34 ссылки, разметка вручную) и 10 контрольных случаев, включая отрицательные. Текущий результат `make eval`: precision 1.000, recall 1.000, F1 1.000 (44 ссылки). Эталон пока маленький, цифры будут падать по мере его расширения.

## Проверка law_aliases.json

`make audit` пишет [docs/aliases_audit.md](docs/aliases_audit.md). Что нашлось в текущей версии:

- у Семейного кодекса (id 8) сокращения записаны с латинской `C` (`CК РФ`); сервис это компенсирует, в данных стоит исправить;
- 580 алиасов вида `ФЗ №7-ФЗ` принадлежат сразу нескольким законам;
- нет Конституции РФ и ФЗ «О банках и банковской деятельности»; нет сокращения `КАС РФ` (id 18);
- около 300 алиасов с непарными кавычками или пометкой редакции в названии;
- 37 коротких названий в кавычках (`«О связи»`, `«О рекламе»`) без номера и даты.

## Структура

```
main.py                 FastAPI: lifespan, DI, /detect, /health
law_links/
  normalize.py          нормализация без изменения длины
  aliases.py            AliasIndex: лемматизация и trie
  grammar.py            цепочки пп./п./ч./ст. и списки значений
  extractor.py          LinkExtractor (Protocol) и RuleBasedExtractor
  schemas.py            LawLink, TextRequest, LinksResponse
data/law_aliases.json   база законов
tests/                  pytest, gold.json
scripts/eval.py         метрики на эталоне
scripts/audit_aliases.py  аудит базы законов
docs/PLAN.md            план, включая фазу 2 (датасет, Space, NER)
```
